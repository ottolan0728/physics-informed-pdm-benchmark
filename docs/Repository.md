\# Repository Organization



This repository is organized to support the reproducibility of the accompanying research paper.



\## Directory Structure



\- \*\*src/\*\*

&#x20; - Source code for data preprocessing, feature engineering, benchmark models, and evaluation.



\- \*\*notebooks/\*\*

&#x20; - Example notebooks demonstrating the experimental workflow.



\- \*\*data/\*\*

&#x20; - Documentation describing how to obtain the public dataset.

&#x20; - No dataset is redistributed in this repository.



\- \*\*figures/\*\*

&#x20; - Figures used in the documentation and reproduced experimental results.



\- \*\*results/\*\*

&#x20; - Generated benchmark results and evaluation outputs.



\- \*\*docs/\*\*

&#x20; - Documentation explaining repository usage and reproducibility.



\- \*\*tests/\*\*

&#x20; - Testing scripts and validation examples.



\## Design Principles



The repository is organized following the principles of:



\- Reproducibility

\- Transparency

\- Maintainability

\- Modularity



The directory structure is intentionally separated to improve readability and facilitate future extensions.
